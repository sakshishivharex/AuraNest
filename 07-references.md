## Notes on Source Selection

- References [1]–[5] are the official documentation for the libraries and engines
  directly used in the implementation.
- References [6]–[8] are the standards governing the protocol and markup formats the
  application depends on.
- References [9]–[11] support the software engineering and database design discussion
  in Chapters 2 and 3.
- Reference [12] is the MDN documentation used for `fetch`, session cookie and
  accessibility-related behaviour in the client-side script.
